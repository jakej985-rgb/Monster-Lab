# 08 Parts Lab

## Goal
Turn the Monster kit inventory into an interactive component encyclopedia.

## Tasks
- Add all 38 peripherals.
- Add component photos/illustrations.
- Add purpose.
- Add pins and pin meanings.
- Add safe operating information.
- Add wiring guidance.
- Add common mistakes.
- Add mini experiments.
- Link each part to lessons.
- Link each part to projects.

## Done When
- A learner can identify a physical component from the app.
- Every supported component has a useful first experiment.
