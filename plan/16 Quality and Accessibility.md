# 16 Quality and Accessibility

## Goal
Make the finished app reliable and usable by kids and parents.

## Tasks
- Add unit tests.
- Add widget tests.
- Add curriculum validation tests.
- Add persistence tests.
- Add navigation tests.
- Add accessibility labels.
- Verify contrast.
- Verify text scaling.
- Verify touch target sizes.
- Test offline behavior.
- Test low-resource devices.
- Test portrait and landscape layouts.

## Done When
- Critical user flows are covered by automated tests.
- Accessibility checks pass.
- Offline curriculum remains functional.
