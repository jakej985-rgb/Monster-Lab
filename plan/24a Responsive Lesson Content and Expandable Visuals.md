# 24a — Responsive Lesson Content and Expandable Visuals

## Goal

Make lesson text, diagrams, screenshots, and visual explanations readable on phone screens.

## Images

Inline images must fit the available width, preserve aspect ratio, and never overflow.

When detail matters, show a clear **Tap to view full image** affordance.

The expanded viewer should provide:

- Full-screen display.
- Zoom.
- Pan where appropriate.
- Back/close.
- Orientation handling.
- Accessibility description.

## Diagrams

For wide diagrams:

- Scale responsively for normal view.
- Allow horizontal scrolling when required.
- Provide full-screen expansion.
- Keep labels readable.

## Cards

Cards must adapt to small portrait, large portrait, and landscape screens.

Avoid fixed widths that cause clipping.

## Markdown

Ensure headings, paragraphs, lists, inline code, and code blocks render correctly on narrow screens.

## Done When

The Lesson 3 visuals shown during development display completely without clipping while detailed diagrams remain inspectable through expansion.
