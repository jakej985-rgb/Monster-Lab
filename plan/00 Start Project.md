# 00 Start Project

## Goal
Establish the Monster Lab project from a clean repository.

## Tasks
- Define Monster Lab as a kid-focused robotics learning app.
- Use the Monster kit archive as the curriculum source.
- Create the Flutter application structure.
- Create the `plan/` directory as the source of truth for project phases.
- Add baseline documentation and development rules.
- Add formatting, analysis, and test configuration.
- Establish the minimum supported Flutter/Dart versions.
- Keep the app offline-first.

## Deliverables
- Working Flutter project.
- `plan/` directory.
- Initial README.
- Passing `flutter analyze`.
- Passing initial test suite.

## Done When
- App launches on the primary development platform.
- Repository has a clean baseline.
- No curriculum or feature work is mixed into setup.
