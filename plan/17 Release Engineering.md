# 17 Release Engineering

## Goal
Prepare production builds for supported platforms.

## Tasks
- Configure Android release builds.
- Configure web release.
- Configure desktop builds where supported.
- Configure versioning.
- Configure release notes.
- Configure build artifacts.
- Configure CI release validation.
- Add crash/error reporting only if appropriate and privacy-conscious.
- Document installation.

## Done When
- A clean machine can install and launch a release build.
- Release builds are reproducible.
