# 14 Interactive Wiring and Code Lab

## Goal
Make wiring and programming interactive learning activities.

## Tasks
- Build visual breadboard representations.
- Add component placement.
- Add wire placement.
- Detect obvious wiring mistakes.
- Highlight expected connections.
- Add Arduino code editor.
- Add syntax highlighting.
- Add code hints.
- Add guided code changes.
- Explain compiler errors in kid-friendly language.

## Done When
- Learners can practice wiring and code changes inside the app before touching hardware.
- The app encourages understanding instead of blind copying.
