# 10 Challenges and Quizzes

## Goal
Make learners apply concepts instead of only following instructions.

## Difficulty
- Rookie.
- Builder.
- Engineer.
- Monster Master.

## Challenge Types
- Identify the part.
- Predict the output.
- Fix the wiring.
- Change the code.
- Debug the logic.
- Build from a goal.
- Explain what happened.
- Combine two components.

## Tasks
- Add question bank.
- Add scoring.
- Add hints.
- Add retry behavior.
- Add XP rewards.
- Add badge conditions.

## Done When
- Each major lesson has at least one challenge.
- Learners can progress without simply memorizing answers.
