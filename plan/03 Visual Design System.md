# 03 Visual Design System

## Goal
Create a consistent visual language that makes robotics approachable for kids.

## Tasks
- Define Monster Lab branding.
- Define typography.
- Define color system.
- Define buttons and controls.
- Define cards.
- Define badges.
- Define progress indicators.
- Define lesson step components.
- Define code display styling.
- Define wiring diagram styling.
- Define accessibility rules.
- Define responsive layouts for phone, tablet, desktop, and web.

## Done When
- Reusable design components exist.
- Every major screen can use the same visual system.
- Text remains readable and controls remain usable on small and large displays.
