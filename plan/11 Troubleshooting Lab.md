# 11 Troubleshooting Lab

## Goal
Teach kids how to debug real electronics.

## Tasks
- Create symptom-based troubleshooting.
- Cover power problems.
- Cover reversed LEDs.
- Cover missing grounds.
- Cover wrong pins.
- Cover loose breadboard connections.
- Cover incorrect libraries.
- Cover compile errors.
- Cover upload errors.
- Cover sensor logic errors.
- Add guided diagnostic questions.

## Done When
- Every major project has common failure paths.
- Troubleshooting teaches a method instead of giving only the answer.
