# 04 App Foundation

## Goal
Build the technical foundation of the Flutter app.

## Tasks
- Create feature-based Flutter folders.
- Configure routing.
- Configure state management.
- Configure local persistence.
- Configure asset loading.
- Configure theme system.
- Configure error handling.
- Configure logging.
- Configure localization-ready strings.
- Configure test structure.
- Configure CI checks.

## Architecture
- Presentation.
- Domain.
- Data.
- Curriculum content.
- Shared UI.
- Services.

## Done When
- Navigation works.
- Persistence works.
- Tests run.
- CI can validate the project automatically.
