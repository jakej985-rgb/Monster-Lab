# 12 Parent Mode

## Goal
Give parents useful progress information without turning the app into a grading system.

## Tasks
- Show learner profiles.
- Show completed lessons.
- Show completed projects.
- Show discovered components.
- Show challenges attempted.
- Show concepts practiced.
- Show recent activity.
- Show areas needing practice.
- Provide curriculum reset controls.
- Provide local data export/import.

## Done When
- A parent can understand progress in under one minute.
- Parent controls do not interrupt normal learner flow.
