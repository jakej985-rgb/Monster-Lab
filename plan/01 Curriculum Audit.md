# 01 Curriculum Audit

## Goal
Convert the Monster kit archive into a verified curriculum inventory.

## Tasks
- Inventory all tutorials.
- Inventory all 38 peripherals.
- Inventory project documentation.
- Inventory project source code.
- Inventory component datasheets.
- Identify duplicate or overlapping lessons.
- Record required components for every project.
- Record prerequisite knowledge for every project.
- Separate beginner, intermediate, and advanced material.
- Flag unsafe or age-inappropriate experiments for restricted handling.

## Deliverables
- Curriculum inventory.
- Component inventory.
- Project inventory.
- Lesson dependency map.
- Safety notes.

## Done When
- Every source item is categorized.
- No app lesson depends on undocumented source material.
