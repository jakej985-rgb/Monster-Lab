# 23d — Curriculum Integration and Prerequisites

## Goal

Connect Coding Foundations, 2A, and 2B to the existing curriculum without breaking the learning path.

## Recommended Order

1. Lesson 1 — Arduino Fundamentals
2. Coding Foundations — optional/placement-based
3. Lesson 2A — Monster Lab Walkthrough
4. Lesson 2B — Arduino IDE Walkthrough
5. Lesson 3 — Libraries
6. Lesson 4 — setup() and loop()
7. Lesson 5 — Blink
8. Continue existing curriculum.

## Prerequisites

- Lesson 1: none.
- Coding Foundations: Lesson 1 recommended.
- 2A: Lesson 1.
- 2B: 2A plus coding baseline.
- Lesson 3: 2B.
- Lesson 4: coding baseline plus 2B plus 3.
- Lesson 5: prior foundations or equivalent placement.

A successful coding assessment can satisfy the coding prerequisite.

## Data Requirements

Support course IDs, lesson IDs, ordering, prerequisites, optional modules, placement, completion requirements, XP, and duration.

## Done When

The prerequisite graph resolves correctly and experienced learners are not unnecessarily blocked.
