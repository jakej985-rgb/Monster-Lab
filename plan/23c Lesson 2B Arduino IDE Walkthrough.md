# 23c Lesson 2B — Arduino IDE Walkthrough

## Goal

Teach how the Arduino IDE works and how a program moves from the computer to the Arduino.

## Teach

- IDE purpose.
- Sketches.
- Code editor.
- Verify.
- Compile.
- Upload.
- Board selection.
- Port selection.
- Serial Monitor.
- Serial Plotter where applicable.
- Libraries.
- Console/errors.

## Core Workflow

Write → Verify → Compile → Upload → Run → Observe.

## First Upload

Guide the learner through safe connection, opening a starter sketch, selecting Arduino Uno and the correct port, verifying, uploading, observing, and confirming the board is running the new program.

## Code Walkthrough

Use a tiny sketch to identify setup(), loop(), function calls, parameters, values, and semicolons.

## Serial Monitor

Teach Serial communication, Serial.begin(), Serial.println(), baud rate, and debugging.

## Troubleshooting

Include no board, wrong board, wrong port, USB problem, compile error, upload error, and baud mismatch scenarios.

## Timing

Target 15–20 meaningful minutes.

## Done When

Learner understands the IDE workflow, board/port selection, Verify vs Upload, first upload, Serial Monitor basics, and common setup failures.
