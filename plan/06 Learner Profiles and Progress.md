# 06 Learner Profiles and Progress

## Goal
Give each child an independent learning journey.

## Tasks
- Create learner profiles.
- Add avatar/name selection.
- Track lesson completion.
- Track project completion.
- Track components discovered.
- Track challenges completed.
- Track quizzes.
- Track XP.
- Track badges.
- Track current level.
- Track last activity.
- Add resume-learning behavior.

## Done When
- Two learners can use the same device without mixing progress.
- Progress survives app restarts.
