# 05 Curriculum Data Engine

## Goal
Make curriculum content data-driven instead of hardcoded into widgets.

## Tasks
- Create lesson schema.
- Create component schema.
- Create project schema.
- Create challenge schema.
- Create quiz schema.
- Create badge schema.
- Create prerequisite schema.
- Create safety metadata.
- Create difficulty metadata.
- Create estimated-time metadata.
- Create required-component metadata.
- Add validation for curriculum files.

## Done When
- A new lesson can be added without changing UI code.
- Invalid curriculum data fails validation clearly.
