## Build Flow
- Requirements.
- Gather parts.
- Wiring step.
- Wiring check.
- Code step.
- Upload.
- Test.
- Troubleshoot.
- Reflection.
- Reward.

## Done When
- Projects are completed one physical step at a time.
- Code is presented with explanation rather than unexplained copy/paste.
