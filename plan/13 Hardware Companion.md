# 13 Hardware Companion

## Goal
Prepare Monster Lab to communicate with real Arduino hardware.

## Phase Scope
- Define supported boards.
- Define connection abstraction.
- Define serial communication layer.
- Detect connected boards where platform permits.
- Read serial output.
- Send test commands.
- Add hardware connection status.
- Keep all hardware features optional.

## Later Capabilities
- Live sensor readings.
- Guided wiring verification.
- Automated project tests.
- Interactive serial monitor.

## Done When
- Hardware support is isolated from curriculum and UI.
- The app still works fully without hardware connected.
