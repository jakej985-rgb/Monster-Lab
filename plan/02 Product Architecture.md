# 02 Product Architecture

## Goal
Define the complete Monster Lab product before building screens.

## Tasks
- Define navigation.
- Define learner flow.
- Define parent flow.
- Define lesson model.
- Define component model.
- Define project model.
- Define challenge model.
- Define quiz model.
- Define XP and badge model.
- Define progress model.
- Define local persistence model.
- Define future hardware integration boundaries.

## Core Areas
- Home.
- Learn.
- Parts Lab.
- Build Lab.
- Challenges.
- Progress.
- Parent Mode.
- Settings.

## Done When
- Every major feature has a defined purpose, data model, and navigation path.
