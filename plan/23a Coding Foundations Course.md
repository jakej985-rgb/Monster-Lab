# 23a Coding Foundations Course

## Goal

Create a standalone beginner programming course so learners understand Arduino code instead of blindly copying it.

## Lessons

1. What Is Code?
2. Variables
3. Operators and Decisions
4. Functions
5. Loops
6. Arduino Code Basics
7. Read and Predict Code
8. Your First Program

## Requirements

Each lesson should target 10–20 meaningful minutes and include explanation, interaction, practice, and assessment.

Teach general programming before relying on Arduino syntax. Include code deconstruction, prediction, debugging, and controlled experiments.

## Placement

- New learner → full course.
- Some experience → placement assessment.
- Experienced learner → assessment and possible skip.

Skipping must not create missing Arduino prerequisites.

## Done When

Course data, all eight lessons, interactive activities, placement, progress, completion, and reusable course support exist.
