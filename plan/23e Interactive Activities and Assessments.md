# 23e — Interactive Activities and Assessments

## Goal

Define reusable activities for Coding Foundations, 2A, and 2B using the interactive infrastructure from Phase 22.

## Coding Foundations

Use code deconstruction, code prediction, variable manipulation, condition simulation, loop simulation, function visualization, code ordering, debugging, and build-a-program activities.

## Lesson 2A

Use navigation exploration, component identification, workflow diagrams, build-flow simulation, code-flow simulation, and an orientation challenge.

## Lesson 2B

Use IDE hotspots, board/port selection, verify/upload workflow, code walkthrough, Serial Monitor simulation, and troubleshooting.

## Rules

- Reuse Phase 22 activity infrastructure.
- Keep activity data separate from widget implementation.
- Provide immediate feedback.
- Persist completion.
- Work offline.
- Provide accessibility metadata.

## Assessment

Prefer prediction, application, troubleshooting, code reading, and workflow decisions over definition-only questions.

## Done When

Every new lesson has interactive activities and assessment using reusable schemas.
