# 07 Learn Lab

## Goal
Build the beginner robotics curriculum.

## Initial Lessons
- What Arduino is.
- How Arduino works.
- Arduino IDE.
- Installing libraries.
- IDE basics.
- First LED blink.
- Potentiometer readings.
- RGB LED basics.

## Lesson Structure
- Short explanation.
- Visual example.
- Physical task.
- Checkpoint.
- Quiz.
- Mini challenge.
- Reward.

## Done When
- Beginner lessons are interactive.
- Learners can complete lessons without reading the original kit documents.
