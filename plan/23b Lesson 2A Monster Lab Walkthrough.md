# 23b Lesson 2A — Monster Lab Walkthrough

## Goal

Introduce Monster Lab before learners are expected to use the Arduino IDE or build hardware.

## Teach

- What Monster Lab is.
- How software and hardware connect.
- Learn.
- Parts Lab.
- Build Lab.
- Code Lab.
- Challenges.
- Progress and XP.
- Safe hardware workflow.

Teach the overall flow: Learn → Explore → Build → Code → Test → Troubleshoot → Master.

## Interactive Activities

- App navigation explorer.
- Find-the-feature challenge.
- Component identification.
- Build workflow simulation.
- Code workflow simulation.
- Final orientation challenge.

## Timing

Target 10–15 meaningful minutes.

## Done When

Learner can locate lessons, components, builds, code, challenges, and progress without a teacher. Activities and completion persist offline.
